Aide de UImaker_noob

Sélectionne un élément au centre : ses paramètres sont dans la fenêtre de gauche, rangés en 3 onglets :

  • Propriétés : nom, boutons, contenu propre au widget, placement des widgets d'un conteneur, états actifs, éléments répétés, notes.
  • Apparence : taille, placement, découpage d'une area, couleurs, marges.
  • Interaction : actif, visible, action, événements.

Cette page explique chaque paramètre. Les réglages d'une instance ou d'un élément répété suivent les mêmes onglets.

Sur iPad, Safari et l'app de l'écran d'accueil peuvent avoir des projets différents. Pour passer de l'un à l'autre, ou de l'iPad au PC, utilise un fichier.

Les areas

Une area est une zone de l'écran. Les areas se découpent et se touchent toujours, sans trou, comme dans Blender. Une area découpée contient d'autres areas ; une area feuille contient des widgets.

Area

ParamètreÀ quoi ça sert
IDIdentifiant court (A1, A2…). Il ne change jamais et n'est jamais réutilisé.
CheminOù elle se trouve : écran > area > area.
Nom (anglais)Nom lu par la session qui codera l'app. Choisis un nom clair : ToolsPanel.
Diviser ⇆ / ⇅Coupe l'area en deux, côte à côte ou l'une sous l'autre.
SupprimerRetire l'area ; sa voisine prend la place. Absent pour l'area principale de l'écran.
→ ModuleEnregistre l'area et son contenu comme module réutilisable. Un module d'area se pose dans une area vide.
Modifier le module / DétacherSeulement si l'area utilise un module : l'ouvrir, ou le transformer en copie indépendante.

Taille dans le découpage

Présent si l'area est dans une area découpée. La taille compte dans le sens du découpage : largeur si côte à côte, hauteur si empilées.

ParamètreÀ quoi ça sert
Mode : Remplir le restePrend la place que les autres laissent.
Mode : Fixe (px)Garde la même taille, même si la fenêtre change.
Mode : ProportionnellePart de l'area parente : 0.25 = un quart.
Taille (px) / ProportionLa valeur du mode choisi.
Min (px) / Max (px)Limites à respecter quand la fenêtre change ou qu'on tire le séparateur. Vide = pas de limite.
Séparateur déplaçable…Dans l'app finale, l'utilisateur pourra tirer le bord après cette area. Testable avec ▶. Dans l'éditeur, tu peux toujours le tirer.

Placement des widgets

Pour une area feuille et pour un widget qui en contient d'autres.

ParamètreÀ quoi ça sert
Mode : PileLes widgets se suivent, l'un après l'autre.
Mode : GrilleLes widgets se rangent en colonnes et lignes.
Mode : Libre (ancrage)Chaque widget est posé où tu veux. C'est le mode d'une nouvelle area.
Direction (pile)Verticale ou horizontale.
Alignement (axe principal)Dans le sens de la pile : start début, center milieu, end fin, spaceBetween réparti.
Alignement (travers)Dans l'autre sens : start, center, end, stretch (un widget en « Remplir » s'étire).
Défilement (pile)auto : on peut faire défiler si ça dépasse. none : ce qui dépasse est coupé.
Colonnes / Lignes (grille)Tailles séparées par des espaces : 120 1fr auto. Nombre = px, 1fr = une part de la place restante, auto = selon le contenu.
EspacementVide entre les widgets, en px (pas en mode libre).
MargesVide entre le bord et les widgets : un champ par côté, et « Les 4 » pour tous d'un coup (pas en mode libre).

Taille et placement

ParamètreÀ quoi ça sert
Largeur / Hauteur : AjusterJuste la place du contenu.
Largeur / Hauteur : RemplirToute la place disponible.
Largeur / Hauteur : FixeUn nombre de px. Les poignées du widget font pareil.
Largeur / Hauteur min et maxLimites, en px. Vide = pas de limite.

État et action

ParamètreÀ quoi ça sert
ActifDécoché : le widget est grisé et ne réagit pas.
VisibleDécoché : il est caché mais garde sa place.
Action du clic / tapCe qui se passe quand on clique ou touche. Voir les actions plus bas.

Événements

« + Événement » : choisis un déclencheur, puis une action. Aussi pour les areas et les écrans. Si plusieurs éléments sont touchés, le plus précis gagne : widget, puis area, puis écran.

Déclencheurs : Clic (souris) / tap · Double clic · Clic droit · Clic du milieu · Survol : entrée · Survol : sortie · Molette · Tap (doigt) · Double tap (doigt) · Appui long (doigt) · Tap du Pencil · Double tap du Pencil (sur le Pencil) (écran) · Squeeze du Pencil Pro (écran) · Raccourci clavier (écran)

Actions : Aucune · Aller à un écran · Ouvrir un écran en fenêtre (dialogue) · Fermer le dialogue · Ouvrir un menu contextuel · Afficher une page (pile de pages) · Afficher / cacher un widget · Changer une variable de test · Action perso (décrite)

ParamètreÀ quoi ça sert

Couleur du texteCouleur du texte et des icônes.
Bordure (épaisseur)Épaisseur du bord en px. 0 = pas de bord.
Bordure (couleur)Couleur du bord.
ArrondiArrondi des coins en px.
Taille du texteTaille du texte en px (n'agit pas sur le widget Texte, qui suit son Rôle).
GraisseÉpaisseur des lettres : 400 normal, 700 gras (n'agit pas sur le widget Texte, qui suit son Rôle).
Marges internesEspace entre le bord et le contenu : un champ par côté, et « Les 4 » pour tous d'un coup. Jamais négatif. Widgets seulement : une area utilise les Marges de son placement.

Les valeurs propres à l'élément passent avant le style lié.

Variables de test

Fenêtre de droite, section « Variables de test ». Une donnée de l'app, pour essayer l'UI.

ParamètreÀ quoi ça sert
NomLe nom de la donnée dans l'app, sans espace : pattern.beats.
TypeNombre, oui / non, ou texte.
Valeur de départ, Min, MaxValeur dessinée, et limites pour un nombre.
DescriptionCe que représente la donnée.
Relier à une répétitionChamp « Relier à la variable » de la répétition (nombre).
Relier à un étatChamp « Variable de test » de l'état (oui / non).
Relier à un texteÉcris {pattern.beats} dans un texte, un bouton, une case ou la valeur d'un champ.
Relier à un boutonAction « Changer une variable de test » : mettre à, ajouter (−1 pour enlever), inverser.
En testLa barre montre chaque variable. La changer garde tes cases et curseurs ; le projet ne change pas. « Réinitialiser » remet tout.

Astuce : glisse vers le haut ou le bas sur un libellé souligné pour changer sa valeur. Un champ qui a des limites ne peut pas les dépasser, à la frappe comme en glissant.

Répétition repeat

Répète un module de widgets : pas d'un séquenceur, lignes d'une liste, vignettes… quand le nombre change dans l'app.

ParamètreÀ quoi ça sert

Nombre d'exempleCombien d'éléments sont dessinés ici. Essaie plusieurs nombres pour voir si l'UI tient (64 au plus).

Nombre dans l'app (source)Ce qui décide du vrai nombre dans l'app, en mots ou en nom de donnée : beat.steps. Lu par le codeur.
Nombre minPlus petit nombre possible dans l'app.
Nombre max (0 = sans limite)Plus grand nombre possible dans l'app. 0 = sans limite.
DirectionHorizontale : côte à côte. Verticale : l'un sous l'autre.

Taille min d'un élément (défile en dessous)Avec « Se partager » ou « Selon une position » : un élément ne devient jamais plus petit, on défile. 0 = pas de limite.
Taille fixe d'un élémentAvec « Taille fixe » ou « Retour à la ligne » : largeur d'un élément, ou hauteur si vertical.

Position dans l'app (source)Avec « Selon une position » : les données qui placent un élément. Lu par le codeur.
